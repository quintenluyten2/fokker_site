## How to add a document

Create a new file in `en/_posts/` named `YYYY-MM-DD-title.md`. Set the front matter:

- `title` — the document title
- `type` — `article`, `image`, or `commentary`
- `source` — the URL of the original source (optional)
- `source_label` — display name for the source link (optional)
